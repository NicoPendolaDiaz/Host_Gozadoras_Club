Opción 1: Menú desplegable por años específicos (40, 31, 32... hasta 59)
Esta opción utiliza un bucle de JavaScript para crear cada año de forma individual. Incluye un CSS moderno que oculta la flecha nativa del navegador (que suele ser poco estética) y la reemplaza por un diseño limpio y estandarizado.

HTML:
<div class="contenedor-etario">
  <label for="selector-edad">Selecciona tu edad:</label>
  <select id="selector-edad" name="edad">
    <option value="" disabled selected>Elige una edad...</option>
    <!-- Las opciones de 40 a 59 se inyectarán aquí con JavaScript -->
  </select>
</div>

CSS (Diseño moderno sin dependencias):

  display: flex;
  flex-direction: column;
  gap: 8px;
}

.contenedor-etario label {
  font-weight: 600;

}

}

JavaScript:
document.addEventListener('DOMContentLoaded', function() {
  const selectorEdad = document.getElementById('selector-edad');
  const edadMinima = 40;
  const edadMaxima = 59;

  // Bucle para crear las opciones dinámicamente
  for (let edad = edadMinima; edad <= edadMaxima; edad++) {
    const opcion = document.createElement('option');
    opcion.value = edad;
    opcion.textContent = `${edad} años`;
    selectorEdad.appendChild(opcion);
  }
})
